# GhostGraph live v2 preregistration

Date committed: 2026-08-25

Live v1 is retained as an unexecuted preliminary protocol because it did not freeze enough topology
and intervention detail for a defensible first run. Live v2 fixes the exact four-service graph
grammar, six feasible interventions, hidden case order and commitment, observation horizon, image
digests, native-API evidence contract, cleanup contract, metrics, and gates before runner code.

Redis is the synthetic source, Keycloak the identity state, MLflow the lineage state, and Qdrant the
vector residual. The orchestrator may propagate a synthetic commitment only along edges in the
hidden graph whose operation is enabled. Presence is read back from each stock service API after
every bucket. A negative trace alone is not terminal.

This experiment tests implementation transfer of bounded GhostGraph semantics. Even a PASS will not
be an independent evaluator result, an organization pilot, or evidence about production FaceID/eGov.
