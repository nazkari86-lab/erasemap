# Independence evidence rubric

This scale prevents project-authored activity from being relabelled as independent evidence.

| Score | Required evidence |
|---:|---|
| 7.8 | Executable blinded protocol exists, but no external evaluator has completed it. |
| 8.5 | A technically valid external package passes commitments, replay, and statistical gates, while evaluator identity/conflicts remain under review. |
| 9.0 | Public evaluator identity, external repository history, authorship timing, and no-conflict declaration are verified; the frozen run passes. |
| 9.5 | The verified evaluator independently authors at least four families and 120 cases, keeps labels hidden until one-shot prediction freeze, signs the complete provenance manifest, and passes every preregistered gate. |
| 9.8 | Two genuinely separate evaluators or one authorized organization replicate the result on materially different systems. |

Current score remains **7.8/10** until an external submission exists. CI, signatures, issue forms,
or cases generated by the EraSeMap author improve readiness but cannot raise independence by
themselves.

The interactive GhostGraph v2 kit is an accepted technical route for collecting blind graph
evidence, but its minimum five-case coverage is a feasibility floor, not by itself the 9.5 event in
this rubric. A 9.5 promotion still requires the scale, authorship, provenance, identity, and
one-shot-freeze gates below, or a documented competition-review amendment approved before reveal.

## Mandatory 9.5 gates

- at least 120 cases, four externally authored families, and 100 non-complete cases;
- verdict accuracy at least 90% and exact shortest-path accuracy at least 80%;
- false-complete Wilson 95% upper bound at most 5%;
- public case/answer commitment before predictions;
- exact EraSeMap commit and answer-blind predictions frozen before label reveal;
- public external challenge repository commit and distinct provenance URL for every family;
- Ed25519 signature binding score, complete manifest, file hashes, identity, and timestamps;
- public identity and conflict-of-interest review by a human maintainer.
