# Синтетический банк EraSeMap

## Что это

Локальный демонстрационный стенд показывает полный цикл проверяемого удаления на 512
полностью синтетических клиентах. Он не подключён к банку, eGov, Face ID или реальным
биометрическим данным.

Для каждого клиента зарегистрированы шесть каналов данных:

| Канал | Синтетический артефакт | Что проверяется |
|---|---|---|
| PostgreSQL KYC | профиль клиента | удалена основная запись |
| Keycloak IAM | личность и сессии | отозваны производные авторизации |
| Redis | кэш входа | удалена быстрая копия |
| Qdrant | шаблон лица | удалён биометрический вектор |
| MinIO | зашифрованный snapshot | закрыт путь восстановления |
| ML channel | влияние на fraud-модель | есть отдельное доказательство для модели |

Итого стенд регистрирует 512 × 6 = 3 072 артефакта. Технологические названия обозначают
контракты локальных синтетических адаптеров, а не доказанную production-интеграцию.

```bash
.venv/bin/erasemap bank-control-plane generate \
  --output outputs/synthetic-bank-control-plane-v1 \
  --customers 512
```

## Сценарий показа жюри

1. Выбрать `Amina S. (synthetic)` и показать шесть активных каналов.
2. Создать запрос на удаление: результат остаётся `INCOMPLETE`.
3. Удалить видимые копии: результат становится `UNVERIFIED`, а не ложным `COMPLETE`.
4. Запустить восстановление snapshot: шаблон лица появляется снова.
5. Запустить ограниченные пробы GhostGraph и локализовать recovery-path.
6. Применить точный deletion cut и повторить replay всех каналов.
7. Получить `COMPLETE`; счётчик защищённых retained-клиентов остаётся 511.

## Fail-closed правила

- Действия разрешены только в зафиксированном порядке.
- Неизвестный идентификатор реального клиента отклоняется.
- Удаление видимых копий не считается доказательством полного удаления.
- Сертификат появляется только после replay зарегистрированной топологии.
- Изменение топологии аннулирует синтетический сертификат.

## Граница утверждений

Стенд доказывает исполнимость API, визуального workflow, fail-closed состояний и
контрактов адаптеров в локальной синтетической среде. Он не доказывает production-ready
интеграцию с PostgreSQL, Keycloak, Redis, Qdrant или MinIO конкретной организации.
Для такого утверждения нужны разрешение организации, реальные mappings, credentials,
полная регистрация топологии и авторизованный внешний pilot.
