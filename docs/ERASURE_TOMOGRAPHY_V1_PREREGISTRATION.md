# Erasure Tomography v1 preregistration

Date frozen: 2026-08-23

## Question

Can three coded synthetic-subject deletion workflows uniquely localize one active recurrence
mechanism from a frozen four-mechanism catalogue, while refusing to localize cases that violate
catalogue, sparsity, execution, or subject-isolation assumptions?

## Frozen scope

The bounded catalogue is backup restore, checkpoint redeployment, legacy export import, and retry
queue replay. All are exercised through the existing local physical carrier laboratory. This is
project-authored prospective evidence, not an external organization or a production eGov/FaceID
deployment.

The exact three-row Boolean matrix, `k=1`, `e=0`, adapter source hashes, schedule commitment, case
counts, baselines, and gates are machine-readable in `benchmark/erasure-tomography-v1.json`.
The committed schedule hash is revealed only in the later result-producing implementation commit.
This locks the schedule prospectively but does not make its author independent of the project.

## Cases

- Eight valid cases: two frozen synthetic-subject trials for each single active mechanism.
- Two safe cases: no recurrence mechanism is active.
- Four negative cases: over-bound support, out-of-catalogue mechanism, skipped workflow, and subject
  cross-contamination.

Every case is executed once in committed order. Development cases use different seeds and are not
part of the confirmatory result.

## Primary outcomes

The experiment records exact-support recovery, false localization, independent bitmask-oracle
agreement, safe no-recurrence decisions, negative-case rejection, post-TRE physical recurrence,
retained synthetic-subject loss, and exact probe counts. Every primary gate must pass; no aggregate
score can compensate for a false localization.

## Baselines

The frozen comparison includes individual audit (four probes), a random feasible three-row matrix,
a greedy separating three-row design, and the existing declared-topology-only path. Baselines use
the same exact decoder where applicable.

## Expected direction, not a result

The hypothesis is that ET will recover all eight valid supports with zero false localization using
three workflows rather than four, reject all four invalid cases, and prevent every localized
physical recurrence after existing TRE controls. These statements are expectations until the
committed runner is executed and independently verified.

## Falsification

The claim fails if a valid case is mislocalized, an invalid case is accepted, production and oracle
disagree, a selected control permits replayed recurrence, or retained synthetic subjects are lost.
A failed v1 result is preserved; changing the protocol or decoder requires a new version.

## Exclusions

No result from this protocol proves catalogue completeness, arbitrary open-world discovery,
production FaceID/eGov/banking transfer, legal compliance, independent external confirmation, or a
worldwide-first claim.
