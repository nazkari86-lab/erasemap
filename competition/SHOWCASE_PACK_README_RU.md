# EraSeMap — пакет для показа жюри

## Порядок показа

1. Откройте `Nurlanuly_Dulat_EraSeMap_Presentation_RU.pptx`.
2. На слайде с демонстрацией откройте `demo-bank/index.html` двойным кликом.
3. Пройдите шесть кнопок справа: запрос → обычное удаление → восстановление → пробы → закрытие пути → сертификат.
4. При вопросах жюри используйте `JURY_DEFENSE_RU.md` и `JUDGE_QA_RU.md`.
5. Передайте `EraSeMap_scientific_paper_RU.pdf` как основную работу. Английская версия лежит рядом.

## Что означает каждый материал

| Материал | Назначение |
|---|---|
| `Nurlanuly_Dulat_EraSeMap_Presentation_RU.pptx` | Презентация для устной защиты |
| `demo-bank/` | Интерактивная синтетическая банковская KYC-демонстрация |
| `demo-evidence/` | Автогенерируемая витрина с live-контрпримером и проверенными показателями |
| `paper-ru/`, `paper-en/` | Финальные научные работы в PDF и редактируемом DOCX |
| `defense/` | Сценарий выступления, Q&A и evidence scorecard |
| `evidence/` | Ключевые воспроизводимые отчёты и протоколы |

## Честная граница утверждений

`demo-bank` — только синтетическая визуальная песочница: она не подключена к банку, eGov, Face ID или реальным биометрическим данным. Она демонстрирует проверяемую логику EraSeMap: обычное удаление может пропустить delayed recovery path; система локализует путь в ограниченном каталоге, применяет действия и выдаёт COMPLETE только после replay-проверки.

Сильные измеримые результаты в `evidence/` относятся только к явно указанным контролируемым протоколам и stock-service transfer. Внешний hidden challenge и организация-пилот ещё не проведены. Не заявляйте их как выполненные.
