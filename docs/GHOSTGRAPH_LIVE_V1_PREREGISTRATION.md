# GhostGraph live v1 preregistration

Date committed: 2026-08-23

This protocol freezes a project-operated transfer test across digest-pinned Redis, Keycloak,
MLflow, and Qdrant containers. Only synthetic subject commitments may be stored. Every published
port must bind to `127.0.0.1`, every managed container must start with
`erasemap-ghostgraph-`, recurrence must be read from a destination service API, and cleanup is a
primary gate.

Four cases are fixed: a multi-hop resurrection path, an observationally path-equivalent pair, a
safe deletion, and an outside-catalogue trace. The run fails closed on image drift, missing native
observations, lifecycle failure, or retained-subject damage. The result directory is append-only.

The runner and any observed result are intentionally absent from this preregistration commit. A
future passing run would demonstrate bounded transfer to these local stock-service versions. It
would not constitute an independent evaluation, production pilot, FaceID/eGov test, legal
compliance determination, or open-world topology discovery.
