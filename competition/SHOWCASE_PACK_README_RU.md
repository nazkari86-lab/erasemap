# EraSeMap — пакет для показа жюри

## Порядок показа

1. Откройте `Nurlanuly_Dulat_EraSeMap_Presentation_RU.pptx`.
2. На слайде с демонстрацией откройте `demo-evidence/index.html` двойным кликом.
3. Пройдите проверяемую последовательность FIND → ERASE → PROVE и откройте итоговый сертификат.
4. При вопросах жюри используйте `JURY_DEFENSE_RU.md` и `JUDGE_QA_RU.md`.
5. Передайте `EraSeMap_scientific_paper_RU.pdf` как основную работу. Английская версия лежит рядом.

## Что означает каждый материал

| Материал | Назначение |
|---|---|
| `Nurlanuly_Dulat_EraSeMap_Presentation_RU.pptx` | Презентация для устной защиты |
| `demo/` | Интерактивная демонстрация этапов FIND-ERASE-PROVE |
| `demo-evidence/` | Автогенерируемая витрина с live-контрпримером и проверенными показателями |
| `paper-ru/`, `paper-en/` | Финальные научные работы в PDF и редактируемом DOCX |
| `defense/` | Сценарий выступления, Q&A и evidence scorecard |
| `evidence/` | Ключевые воспроизводимые отчёты и протоколы |

## Честная граница утверждений

`demo-evidence` — локальная витрина доказательств EraSeMap. Она показывает проверяемую логику: локальный статус удаления может пропустить отложенный путь восстановления; система локализует путь в ограниченном каталоге, применяет разрешённые действия и выдаёт `COMPLETE` только после повторной проверки.

Числа в `evidence/` относятся только к указанным контролируемым протоколам и проверке на готовых сервисах. Внешний hidden challenge и пилот в организации ещё не проведены. Не выдавайте их за готовые результаты.
